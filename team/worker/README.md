# 해랑 업무 서버 (직원용 협업툴)

화면 주소: https://haerangtkd.github.io/team/

- Cloudflare Worker `haerang-team` + D1 데이터베이스 `haerang-team` (학부모 앱·출석부와 따로)
- 설정(Bindings): D1 `DB` → `haerang-team`, Service binding `ATT` → `haerang-attendance`, Secret `SYNC_KEY` (출석부와 같은 값)
- 첫 화면에서 처음 들어온 사람이 이름·PIN을 정하고, 설정에서 다른 사람을 추가합니다.

## 기능
- 홈: 할 일(맨 위), 등원·픽업표(요일별 기본 명단 + 날짜별 수정, 누르면 데려옴 ✓, 길게 누르면 결석), 다가오는 일정, 행사·구매
- 채팅: 사진, 해시태그
  - `#일정 11/20 3시 승급심사` → 일정 자동 등록
  - `#할일 현수막 주문 내일` → 할 일 추가
  - `#구매 미트 2, 띠 10` → 진행 중인 구매표에 추가
  - `#등원 지민 결석` → 등원표 결석 + 출석부에 결석 예정 / `#등원 서준 데리러` → 등원표에 추가
  - 해시태그 없이 날짜가 있으면 메시지 아래 [일정으로 등록] 버튼
- 일정: 달력, 댓글
- 표: 행사 인원표(품목·금액 합산, 사이즈 등 선택, 체크 칸, 결제확인·지급·하원차, 대기자, 비회원), 물품 구매표
- 알림: 채팅·댓글·체크·수정 모두 (내가 한 건 빼고). 아이폰은 홈 화면에 추가한 앱에서 알림 켜기
- 앱 아이콘 숫자: 남은 할 일 + 새 채팅

## 무료 사용량
화면을 보고 있을 때만 새 내용을 받아 옵니다(채팅 4초, 다른 화면 15초). 3~4명이 하루 종일 써도 하루 1만 번 안쪽이라 학부모 앱·출석부와 합쳐도 무료 한도(10만 번) 안입니다.
