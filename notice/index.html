해랑경희 태권도장

다른 브라우저에서 열어 주세요

카카오톡이나 인스타그램 안에서는 알림을 받을 수 없습니다. 아래 버튼을 누르거나, 오른쪽 위 메뉴에서 다른 브라우저로 열기를 선택해 주세요.

브라우저로 열기

홈 화면에 추가해 주세요

아이폰에서는 홈 화면에 추가해야 앱처럼 쓰고 알림도 받을 수 있습니다. Safari에서 아래 순서대로 진행해 주세요.

  1. 화면 아래(또는 위)의 공유 버튼 누르기
  2. 메뉴를 내려서 홈 화면에 추가 누르기
  3. 오른쪽 위 추가 누르기
  4. 홈 화면에 생긴 해랑경희 아이콘으로 열기

Safari가 아닌 다른 앱에서 열었다면 주소를 복사해 Safari에서 열어 주세요.

이 기기에서는 쓸 수 없습니다

휴대폰 운영체제를 최신 버전으로 업데이트한 뒤 다시 열어 주세요. 아이폰은 iOS 16.4 이상이 필요합니다.

준비 중입니다

곧 시작합니다. 조금만 기다려 주세요.

학부모 가입

가입하면 등원·하원 알림, 알림장, 공지, 앨범, 출석부를 이 휴대폰에서 볼 수 있습니다.

도장에 등록된 이름 그대로 적어 주세요.
