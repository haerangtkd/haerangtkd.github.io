해랑경희 태권도장

Safari·Chrome으로 열어 주세요

카카오톡·인스타그램 안에서는 앱을 설치하거나 알림을 받을 수 없어요. 아이폰은 Safari, 갤럭시(안드로이드)는 Chrome으로 열어 주세요.

브라우저로 열기

초대번호
앱을 설치한 뒤 가입할 때 이 번호를 넣어 주세요. 먼저 복사해 두세요.

홈 화면에 추가해 주세요

아이폰에서는 홈 화면에 추가해야 앱처럼 쓰고 알림도 받을 수 있습니다. Safari에서 아래 순서대로 진행해 주세요.

  1. 화면 아래(또는 위)의 공유 버튼 누르기
  2. 메뉴를 내려서 홈 화면에 추가 누르기
  3. 오른쪽 위 추가 누르기
  4. 홈 화면에 생긴 해랑경희 아이콘으로 열기

Safari가 아닌 다른 앱에서 열었다면 주소를 복사해 Safari에서 열어 주세요.

먼저 앱을 설치해 주세요

홈 화면에 해랑경희 앱을 설치한 뒤, 그 앱에서 가입해 주세요. 설치하면 알림도 더 잘 옵니다.

  1. 화면 아래 오른쪽 ≡ (메뉴) 누르기
  2. 현재 페이지 추가 (또는 페이지 추가) 누르기
  3. 홈 화면 누르기 → 추가
  4. 홈 화면에 생긴 해랑경희 아이콘으로 열기
  1. 오른쪽 위 ⋮ (점 세 개) 누르기
  2. 앱 설치 또는 홈 화면에 추가 누르기
  3. 설치 누르기
  4. 홈 화면에 생긴 해랑경희 아이콘으로 열기
설치했습니다. 이 화면을 닫고 홈 화면의 해랑경희 아이콘으로 열어 주세요.

휴대폰 운영체제를 최신 버전으로 업데이트한 뒤 다시 열어 주세요. 아이폰은 iOS 16.4 이상이 필요합니다.
